## Estructura del Repositorio y Entregables
Este repositorio contiene la entrega técnica requerida evaluada bajo los 5 criterios de la rúbrica (20% c/u):

1. **`Ecosistema_Automatizacion_IA_Coderhouse.pdf`**: Documentación técnica oficial que cubre:
   - **Criterio 1:** Mapa de arquitectura visual de extremo a extremo (Airtable Trigger -> RAG Search -> OpenAI -> Router HITL -> Gmail Output).
   - **Criterio 2:** Estructura de datos normalizada de las tablas de Airtable y esquemas JSON de las APIs de OpenAI y Gmail.
   - **Criterio 3:** Matriz de decisión y optimización de costos (GPT-4o-mini vs. Claude 3.5 Sonnet vs. Batch API con cálculo de ROI y 93.3% de ahorro).
   - **Criterio 4:** Políticas de seguridad, minimización de datos, Error Handling con directiva *Resume* y compuerta *Human-in-the-loop* (anti-efecto metralleta).
   - **Criterio 5:** Dashboard de control con métricas de tasa de aprobación, volumen y tasa de errores.
2. **`flujo_make.blueprint`**: Archivo de respaldo técnico con la configuración completa del escenario de Make.
3. **Evidencias Gráficas**: Capturas de pantalla de la ejecución exitosa del flujo y del panel de control de Airtable.
